# Syncraft Launcher

Syncraft 是一个面向 Minecraft 私服的桌面启动器，依赖一个网络上的 syncraft-server 实例。提供同步文件、账号验证、定制主页等功能。

## 使用

1. 在「服务器」页填写服务器地址并连接。
2. 在「账号」页登录 Syncraft 账号，或添加离线账号。
3. 回到主页，点击底部按钮开始游戏；首次启动会自动安装并同步所需文件。

设置页可以调整游戏目录、Java、下载源与下载并发数。

## 系统要求

- Windows、macOS 或 Linux
- 已安装 Java（启动器会自动检测，也可以在设置里手动指定）

## 获取帮助

遇到问题请联系你所游玩的服务器的管理员。
